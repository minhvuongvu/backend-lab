    backend-lab

    Nguồn: README.md (trang này tự sinh)

    "Phòng thí nghiệm" để nghiên cứu sâu từng công nghệ/kỹ thuật backend (Java/Spring Boot, PostgreSQL, Redis, Kafka...) theo quy trình 7 phase, kiểm chứng bằng thí nghiệm thật thay vì chỉ đọc tài liệu.

    PhaseNội dungNơi ghi
    1Research: bối cảnh, lý thuyết, các cách implement, đánh đổi01-research.html
    2System design: hệ thống tối giản, before/after02-system-design.html
    3Implement: code + hướng dẫn từng bướcsystem/ + 03-implementation.html
    4Experiment plan: thí nghiệm trước/sau04-experiment-plan.html
    5Execute: chạy, đo, báo cáo số liệuexperiments/ + results/ + 05-results.html
    6Conclusion06-conclusion.html
    7Production rollout07-production.html + deploy/

    Mỗi topic so sánh before (hệ thống as-is) với từng cách implement. 14 mục tiêu học và nơi trả lời: xem CLAUDE.md. Tài liệu là HTML: mở trực tiếp bằng trình duyệt (cần internet để tải mermaid/highlight.js).

    Quy tắc chung cho mọi phiên Claude Code nằm trong CLAUDE.md.

    Cách dùng

    • Mở Claude Code trong backend-lab/.
    • /research transactional outbox: chạy phase kế tiếp, dừng ở các điểm duyệt.
    • /research transactional outbox 5: chạy riêng một phase.
    • /research idempotency key all: chạy một mạch, các điểm cần duyệt ghi vào README của topic.
    • /research cache stampede lite: chế độ học nhanh (ít kịch bản, bỏ phase 7); nâng lên đầy đủ sau bằng /research cache stampede full.
    • /lab-status: xem tiến độ mọi topic và gợi ý topic nên học tiếp theo lộ trình.
    • /research cdc debezium spike: khám phá nhanh một hiện tượng; /research redis lock vs postgres advisory lock: topic so sánh hai công nghệ.
    • /research case-payment-system: case study tổng hợp — ghép nhiều topic đã học thành một hệ thống và kiểm chứng end-to-end (giai đoạn 8 trong lộ trình).
    • Trang tổng (mở bằng trình duyệt): hub/lab.html tổng quan · hub/roadmap.html lộ trình · hub/problems.html tra theo vấn đề · hub/insights.html kho insight · hub/benchmarks.html số liệu tham chiếu · hub/glossary.html thuật ngữ.
    • Một chủ đề, một phiên. Dùng /clear khi chuyển chủ đề để context không bị lẫn.
    • make obs-up trước phase 5 nếu muốn xem metric trên Grafana.
    • Yêu cầu: Docker, JDK 21, k6, Python 3 (và GNU make + bash; trên Windows dùng Git Bash/WSL).

    Lệnh make

    LệnhTác dụng
    make new-topic SLUG=<kebab-case>Tạo topic mới từ templates/ (cách duy nhất để tạo topic)
    make obs-upBật observability đầy đủ: metrics, logs, traces, profiles (Grafana http://localhost:3000, admin/admin)
    make obs-up OBS=metricsChỉ Prometheus + Grafana + docker-stats (overhead thấp nhất, dùng khi đo hiệu năng thuần)
    make obs-statusTrạng thái container và health của các target Prometheus
    make obs-downTắt observability stack
    make insightsDựng lại hub/insights.html từ mọi topic và kiểm tra cấu trúc insight
    make hubsDựng lại mọi trang tổng (LAB, INSIGHTS, PROBLEMS, GLOSSARY, BENCHMARKS) và mục Topic liên quan
    make roadmapĐánh số thứ tự học, xếp nhóm theo giai đoạn và kiểm tra tiền đề / lộ trình trong hub/roadmap.html
    make hubs-checkKiểm tra markup insight / vấn đề / thuật ngữ / số liệu của mọi topic
    make doctorKiểm tra máy: công cụ, JDK 21, Docker, cổng (theo lab.env), TLS, git remote
    make analysis-imageBuild image phân tích pin version (pandas + matplotlib) ở shared/analysis/
    make analysis CMD="python scripts/stats.py ..."Chạy lệnh Python trong image phân tích, repo mount tại /lab (không cần pip trên máy)
    make checkMọi kiểm tra: unit test, linter roadmap/trang tổng, trang sinh ra còn mới, cú pháp, render

    Cổng riêng của máy (khi 9090/3000/4317… bị chiếm): cp lab.env.example lab.env rồi sửa. File lab.env không commit; Makefile gốc và experiments/Makefile của mọi topic tự nạp, nên make obs-up, thí nghiệm và k6 dùng cùng cổng. Ghi đè tạm một lần vẫn được: make obs-up GRAFANA_PORT=13001. Cách nối app, exporter, k6 và xuất số liệu vào results/raw: shared/observability/README.md.

    Cấu trúc

    backend-lab/
├── index.html                # trang chủ (sinh từ README.md) — mở file này trong trình duyệt
├── README.md                 # nguồn của index.html; GitHub hiển thị file này
├── CLAUDE.md                 # nguyên tắc cốt lõi cho mọi phiên (cùng .claude/rules/ là nguồn của hub/rules.html)
├── lab.env.example           # mẫu cổng riêng của máy → copy thành lab.env (không commit)
├── Makefile                  # make help: doctor, obs-*, new-topic, roadmap, hubs, check, hooks…
├── hub/                      # các trang tổng, dùng chung thanh điều hướng
│   ├── lab.html              #   tổng quan tiến độ, chờ duyệt, topic sẵn sàng học
│   ├── roadmap.html          #   lộ trình 8 giai đoạn (bảng là nguồn dữ liệu, sơ đồ tự sinh)
│   ├── problems.html         #   tra theo triệu chứng → nguyên nhân, lựa chọn, runbook
│   ├── insights.html         #   kho insight + chuyên đề của mọi topic
│   ├── benchmarks.html       #   số liệu tham chiếu đã đo
│   ├── glossary.html         #   thuật ngữ chung
│   └── rules.html            #   bản HTML của CLAUDE.md + .claude/rules/
├── topics/<slug>/            # mỗi topic: README.html + 01…07 + system/ + experiments/ + results/ + deploy/
├── templates/                # khung tài liệu cho mỗi topic
├── shared/docs/              # CSS/JS dùng chung cho mọi trang HTML
├── shared/scaffold/          # bộ khung Spring Boot + experiment kit, copy vào mỗi topic khi tạo
├── shared/observability/     # Prometheus, Loki, Tempo, Pyroscope, Alloy, Grafana dùng chung
├── shared/analysis/          # image Python pin version để xử lý số liệu, vẽ biểu đồ
├── scripts/                  # new-topic, doctor, stats, prom_export, roadmap_order, build_* (trang tổng), check_render
├── tests/                    # unit test cho các script (make test)
└── .claude/                  # /research, /lab-status, subagent lab-reviewer, rules/ (quy tắc chi tiết theo loại file)

    Trang HTML tự sinh (index.html, hub/*.html trừ roadmap.html) không sửa tay: sửa nguồn rồi chạy make hubs.
